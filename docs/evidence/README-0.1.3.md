# mesh-agent



## Описание

Агент звукозаписи для МОС (Операционная система «Московской электронной школы»). 

Работает в фоне и записывает звук с входящих устройств по расписанию. Получает список сетевых устройств и их MAC адреса.
Написан на Go

## Сборка и запуск

Для сборки необходимо установить язык go следующей командой
```
dnf install go
```
После установить дополнительные библиотеки в систему командой
```
dnf install glibc-devel
```
```
dnf install opus-devel
```
```
dnf install libopus-devel
```
```
dnf install libopusfile-devel
```
```
dnf install lib64opusfile-devel
```

Запуск проекта осуществляется командой
```
go run .
```
