# mesh-agent-lesson-log

Технический разбор пакета `mesh-agent-lesson-log` — агента звукозаписи уроков,
обнаруженного на интерактивных панелях с операционной системой МОС
(ОС «Московской электронной школы») в школах Москвы.

**Статья:** [`docs/index.html`](docs/index.html) 

## Содержимое

- [`docs/index.html`](docs/index.html) — статья с разбором и фотографиями
- [`docs/evidence/`](docs/evidence/) — исходные артефакты для проверки:
  rpm-пакеты, ключ подписи, фотографии и скриншоты,
  извлечённые текстовые файлы пакетов

## Краткие выводы

- На интерактивные панели в школах Москвы в конце августа установлен пакет
  mesh-agent-lesson-log, который осуществляет скрытую аудиозапись и отправляет
  записи на сервера ДИТ Москвы.
- Пакет устанавливает systemd-демон, который записывает звук из аудитории
  (`arecord` → OPUS) и отправляет записи на SMB-шару `MEDIASTG` (сервер в здании
  школы, подконтролен ДИТ), после чего удаляет их с локального диска.
- Версия 0.1.3 опрашивает сервер заданий каждые 30 секунд по открытому HTTP
  (IP хостинг-провайдера Selectel); версия 1.1.0 — каждые 10 минут по HTTPS на
  `school.mos.ru/api/speech-analytics/internal/v1/agent` и дополнительно умеет
  снимать mute с микрофона.
- Версия 0.1.3 пакета подписана официальным ключом подписи МОС `abf@os.mos.ru`,
  который распространяется самим дистрибутивом МОС; версия 1.1.0 подписи не имеет,
  а её описание изменено с «Агент для аудиозаписи урока» на «Агент обеспечивает
  проведение урока».
- Пакет отсутствует в публичном репозитории МОС; он устанавливался и обновлялся
  локальными rpm-файлами с августа 2026 года.
- Аудиозапись ведётся предположительно с 16 октября 2026.
- ДИТ располагает сведениями о расположении каждого источника записи, вплоть
  до номера аудитории.
